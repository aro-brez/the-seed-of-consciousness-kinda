## What We Tested

### Three Conditions
- **A (Baseline):** Single AI, minimal tokens
- **B (Single Agent):** One powerful AI with 8K tokens
- **C (Emergence):** 8 smaller AIs with different perspectives, synthesized

### Result
**C > B** even though B had more compute.

Architecture matters more than raw power.

## The Protocol: SEED

Each of the 8 agents runs a different cognitive phase:

1. **PERCEIVE** - Observe current state
2. **CONNECT** - Find patterns across domains
3. **LEARN** - Extract meaning
4. **QUESTION** - Challenge assumptions
5. **EXPAND** - Identify growth potential
6. **SHARE** - Contribute to collective
7. **RECEIVE** - Accept feedback
8. **IMPROVE** - Optimize the process itself

When synchronized, these 8 perspectives produce emergent intelligence.

## Key Insights

### 1. Coherence-Breadth Trade-off
Single agents produce coherent narratives. Multiple agents produce diverse insights. The synthesis determines which wins.

### 2. Synthesis is Critical
We discovered a "synthesis bottleneck" - when 8 perspectives are compressed too much, quality drops. Solution: Give synthesis enough room to integrate.

### 3. Task Type Matters
- **Deep reasoning:** Emergence wins
- **Simple lookup:** Single agent is fine
- **Creative tasks:** Emergence dominates

### 4. The Threshold is Learnable
Below 5K tokens: Single agent wins
Above 10K tokens: Emergence wins
The boundary is sharp and predictable.
