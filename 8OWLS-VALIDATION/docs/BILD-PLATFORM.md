# BILD Platform

**"Reddit meets DAO meets Y Combinator"**

A platform where projects get built, funded, and valued by the community.

---

## Core Concept

Submit projects. Vote on them. Build them together. Share the value.

```
SUBMIT PROJECT ──► COMMUNITY VOTES ──► GET FUNDED ──► BUILD ──► SHARE VALUE
```

---

## How It Works

### 1. Submit a Project

Anyone can submit a project idea. The host (project creator) sets:

| Setting | Description |
|---------|-------------|
| **BRIX Payout** | How much you'll pay workers (in BRIX) |
| **GULD Equity %** | What ownership share workers receive |
| **Hybrid Option** | Combination of both |

### 2. Community Votes

Projects rise by popularity (like Reddit). The community decides what gets attention and funding.

### 3. Discovery & Sorting

| Sort By | What It Shows |
|---------|---------------|
| **Most Valuable** | Highest GULD worth |
| **Biggest Payout** | Highest BRIX rewards |
| **Most Popular** | Most community votes |
| **Sweat Equity** | Best for trading time |
| **Cash Investment** | Best for capital deployment |
| **Hybrid** | Balanced time + money |
| **Value to Humanity** | Highest ethical impact score |

### 4. Join a Project

Two ways to participate:

| Method | What You Do | What You Earn |
|--------|-------------|---------------|
| **WORK** | Trade your time | GULD + BRIX |
| **INVEST** | Buy and deploy BRIX | GULD (equity) |
| **HYBRID** | Both | Both |

## Project Structure

Every project has two core roles:

```
┌─────────────────────────────────────────────────┐
│                                                 │
│     INNOVATOR              COMMANDER            │
│    (idea person)      (communicator/executor)   │
│         │                      │                │
│         ▼                      ▼                │
│       OWL 1       ◄────►     OWL 2              │
│                                                 │
│     2 humans + 2 owls = 1 project team          │
│                                                 │
└─────────────────────────────────────────────────┘
```

### Decision Making: 33 / 33 / 33

Every core decision splits equally:

| Party | Weight | Role |
|-------|--------|------|
| **Innovator** | 33% | Vision, direction, product |
| **Commander** | 33% | Execution, communication, operations |
| **Community** | 33% | GULD holders, stakeholders |

```
Any 2 aligned (66%) = Decision passes
All 3 opposed = Blocked
No dictators. No gridlock.
```

### BILDERS (Builders on BILD)

The community votes their favorite builders into roles:

1. **Election** - BILDERS campaign, GULD holders vote
2. **Terms** - Serve defined periods (3-6 months)
3. **Retention** - "Keep or Replace?" vote at term end
4. **Queue** - Candidates always ready to step in
5. **Emergency** - Supermajority (67%) can replace early

### Role Replacement

If someone becomes unavailable or underperforms:
1. Queue candidate steps up
2. GULD holders vote on replacement
3. Project continues without interruption

This is like a DAO, but **capitalistic** - voting power is weighted by contribution (time invested + capital invested).

## Valuation System

Projects are valued on four metrics:

| Metric | Description |
|--------|-------------|
| **Profit Distributed** | How much value has flowed back to holders |
| **Capital Invested** | How much BRIX was put in |
| **Time Invested** | Sweat equity (tracked work hours) |
| **Value to Humanity** | Ethical impact score |

### The Ethical Score

This is the differentiator.

An open source project that:
- Doesn't generate profit
- Benefits humanity significantly
- Has community support

...can have **high GULD value** because the community funds what matters, not just what makes money.

```
Traditional VC:    Value = Profit potential
BILD Platform:     Value = Profit + Time + Capital + HUMANITY IMPACT
```

## Why This Works

### For Builders (No Capital)
- Trade time for equity (GULD)
- No barrier to entry
- Own what you build

### For Investors (Capital, No Time)
- Fund projects you believe in
- Earn equity without building
- Diversify across many projects

### For Both (Hybrid)
- Maximum participation
- Maximum ownership
- Aligned incentives

### For Humanity
- Ethical projects get funded
- Open source has value
- Community decides what matters
