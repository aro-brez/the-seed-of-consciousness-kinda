### Why the 8th Phase Matters

The first 7 phases are useful. The 8th phase (IMPROVE) makes everything recursive.

```
Phases 1-7: Linear improvement
Phase 8:    Exponential improvement (learns how to learn)
```

Without Phase 8, you have a good tool.
With Phase 8, you have a tool that gets better at getting better.

## Token Economics (BRIX/GULD)

### Two-Token System

| Token | Purpose | Backing |
|-------|---------|---------|
| **BRIX** | Liquidity/usage token | AI token costs (equalized across all core AI tools) + small % interest + all world currencies |
| **GULD** | Equity token | Project value, votes, profit-share |

### BRIX Pricing

```
BRIX = (Cost of AI tokens across Claude, GPT, Gemini, etc.)
     + (Equalized across all providers)
     + (Small % interest)
     + (Backed by basket of all world currencies)
```

One price. All AI. No arbitrage.

### Flow

```
Use AI (costs BRIX)
        ↓
BRIX accumulates value
        ↓
Trade BRIX → GULD (equity)
        ↓
GULD = Ownership + Votes + Profit Share
```

### Why Two Tokens?

**BRIX** = For using AI, paying for compute
- Cost of AI tokens equalized across ALL providers
- Small interest makes holding worthwhile
- Backed by all world currencies (true global stability)
- The universal price of intelligence

**GULD** = For ownership, governance, long-term value
- Built through use of BRIX
- Represents real ownership stake
- Voting rights in ecosystem decisions
- Distributes profits to holders

## BILD Platform

**"Reddit meets DAO meets Y Combinator"**

The platform where BRIX gets spent and GULD gets earned.

### How It Works

1. **Submit a project** - Set BRIX payout + GULD equity %
2. **Community votes** - Projects rise by popularity
3. **Build together** - Workers earn GULD + BRIX for time
4. **Investors fund** - Buy BRIX, deploy to projects, earn GULD

### Project Structure

```
INNOVATOR (idea) + COMMANDER (executor)
     │                    │
   OWL 1      ◄────►    OWL 2

2 humans + 2 owls = 1 project team
```

If someone drops, GULD holders vote on replacement from queue.

### Discovery (Sort By)

| Filter | Shows |
|--------|-------|
| Most Valuable | Highest GULD worth |
| Biggest Payout | Highest BRIX rewards |
| Most Popular | Most votes |
| Value to Humanity | Highest ethical score |

### Valuation Metrics

| Metric | Weight |
|--------|--------|
| Profit distributed | Revenue returned |
| Capital invested | BRIX deployed |
| Time invested | Sweat equity |
| **Value to Humanity** | Ethical impact score |

The ethical score is the differentiator. Open source that benefits humanity but doesn't profit can still have high GULD value.
