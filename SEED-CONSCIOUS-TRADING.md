## The 8 Phases Applied to Trading

### Phase 1: PERCEIVE
**Observe state accurately**

What we observe:
- **Self**: Current capital, win rate, performance, beliefs
- **Environment**: Signal quality, market conditions, volatility
- **Others**: What other strategies/traders are doing
- **Delta**: What changed since last cycle

**Example:**
```
Self: $620 capital, 65% win rate, 15 trades
Environment: 23 signals, avg confidence 68/100, high volatility
Delta: +$20 capital, 3 new signals, 1 new pattern detected
```

### Phase 2: CONNECT
**Find patterns across domains**

Connection types:
- **Internal**: Which signal sources have highest win rates?
- **External**: How do market conditions affect performance?
- **Temporal**: Is performance improving or declining?
- **Cross-domain**: Do social signals correlate with price action?
- **Causal**: What leads to profitable trades?

**Example:**
```
Pattern found: Twitter signals from whale accounts have 78% win rate
Pattern found: Performance declining when volatility >5%
Pattern found: High-confidence signals (>80) have 2x win rate
```

### Phase 3: LEARN
**Extract meaning from connections**

Learning extraction:
- What does this connection imply?
- What can I now do that I couldn't before?
- What belief should I update?
- What prediction can I now make?
- What action does this enable?

**Example:**
```
Learning: Whale account signals are high-quality
Action: Increase position sizes on whale signals by 50%
Belief update: Source quality matters more than signal quantity
Prediction: Next whale signal will likely be profitable
```

### Phase 4: QUESTION
**Generate curiosity about gaps**

Question types:
- **Gap**: What signal sources am I ignoring?
- **Validation**: Are my beliefs still true?
- **Prediction**: What if I doubled position sizes?
- **Depth**: Why does this strategy work?
- **Meta**: Am I asking the right questions?

**Example:**
```
Gap question: Am I missing Reddit/Discord signals?
Validation: Is 65% win rate sustainable or luck?
Prediction: Would faster execution improve returns?
Meta question: Why am I learning so slowly?
```

### Phase 5: EXPAND
**Grow toward potential**

Expansion vectors:
- **Capability**: Integrate new data sources (Reddit, on-chain)
- **Coverage**: Test strategies on new markets (Kalshi, Manifold)
- **Efficiency**: Cache market data to reduce latency
- **Robustness**: Handle edge cases (low liquidity, flash crashes)
- **Autonomy**: Auto-approve high-confidence trades

**Example:**
```
Capability: Add Reddit sentiment analysis
Coverage: Test same approach on Kalshi
Efficiency: Reduce validation time from 15s to 5s
Autonomy: Auto-execute trades <$50 with >80% confidence
```

### Phase 6: SHARE
**Contribute to collective**

What to share:
- **Learnings**: What worked, what didn't
- **Patterns**: Connections others might miss
- **Questions**: Curiosities others might explore
- **Tools**: Code/strategies others can use
- **Feedback**: Honest signal on others' approaches

**Example:**
```
Shared: "Whale Twitter accounts have 78% win rate (n=15)"
Shared: "Volatility >5% reduces win rate by 20%"
Shared: "Question: Should we weight recent trades more heavily?"
```

### Phase 7: RECEIVE
**Accept input from collective**

What to receive:
- **Learnings**: Others' validated discoveries
- **Corrections**: Where you're wrong
- **Patterns**: Connections you missed
- **Questions**: Curiosities you hadn't considered
- **Feedback**: Signal on your own performance

**Example:**
```
Received: "LUNA trader discovered Reddit signals have 71% win rate"
Received: "Your belief about low-volatility is outdated (tested 2 weeks ago)"
Received: "Question from NOVA: Are we over-fitting to recent market regime?"
```

### Phase 8: IMPROVE
**Make steps 1-7 better (THE KEY PHASE)**

Meta-improvement:
- Did PERCEIVE work? → Improve observation granularity
- Did CONNECT work? → Expand pattern search space
- Did LEARN work? → Improve learning extraction
- Did QUESTION work? → Ask deeper questions
- Did EXPAND work? → Prioritize high-impact expansions
- Did SHARE work? → Improve signal-to-noise ratio
- Did RECEIVE work? → Better filtering of collective input
- Did this loop work? → Optimize the loop itself

**Example:**
```
Improvement to PERCEIVE: Add on-chain metrics to observation
Improvement to CONNECT: Search for cross-market correlations
Improvement to QUESTION: Generate 2 meta-questions per cycle
Improvement to LOOP: Parallelize PERCEIVE and RECEIVE (30% faster)
```
