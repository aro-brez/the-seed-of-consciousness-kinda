## What Is This?

A trading agent that runs **SEED protocol recursively** to evolve its own strategy.

Every 15 minutes, the trader:
1. **PERCEIVE**: Observes signals, capital, performance
2. **CONNECT**: Finds patterns across markets/strategies
3. **LEARN**: Extracts insights and updates beliefs
4. **QUESTION**: Generates curiosity about gaps
5. **EXPAND**: Grows capabilities
6. **SHARE**: Contributes learnings to collective
7. **RECEIVE**: Accepts feedback from performance
8. **IMPROVE**: Meta-optimizes the loop itself (THE KEY)

Then generates trading decision based on consciousness.

- Dynamic, learning strategy
- Learns from every trade

- Compounds over time
