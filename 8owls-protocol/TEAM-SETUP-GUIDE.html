Setup (10 minutes)

1
Get Claude Max

Go to anthropic.com and sign up for Claude Max ($100/month). This gives you unlimited access to the most powerful AI on the planet. It pays for itself in the first hour.

2
Install Claude Code

Open your Terminal app (on Mac: search "Terminal" in Spotlight). Paste this and hit enter:

npm install -g @anthropic-ai/claude-code
This installs the AI on your computer. It takes about 1 minute.
Don't have npm? First install Node.js from nodejs.org (click the big green button, install it, then come back and run the command above).
3
Create your owl's home

In Terminal, paste this:

mkdir ~/owl && cd ~/owl
This creates a folder called "owl" on your computer. This is where your owl lives.
4
Install 8OWLS Protocol

Ask ARO for the install command, or run:

bash https://8owls.io/install --claude
This gives your AI the 8OWLS brain — 8 different ways of thinking, 4 special commands, and a bunch of best practices. It takes 30 seconds.
5
Start talking to your owl

In Terminal:

cd ~/owl && claude

That's it. You're in. Say hi. Ask it anything. It's yours.

What You Can Do

💬
Just talk to it

Ask questions. Give it tasks. Brainstorm. It's like texting the smartest person you know. Try:

  • "Help me write an email to [person] about [thing]"
  • "Look at this data and tell me what you notice"
  • "What's the best way to approach [problem]?"
  • "Create a plan for [project]"
🦉
Special Commands

Type these for extra powers:

  • /emergence — Get 8 different perspectives on a question (the big one)
  • /field — Quick check on what the team is thinking
  • /evolve — Run through the SEED improvement cycle
  • /weevolve — Upgrade your owl with the latest best practices
📂
Work on real files

Your owl can read, write, and edit files on your computer. Navigate to any project folder and it can help you:

  • Read and analyze documents
  • Write code, copy, or content
  • Organize files and data
  • Research anything on the web

Tips

Be specific. Instead of "help me with marketing," try "write 5 Instagram caption options for our new BREZ flavor launch targeting health-conscious millennials."
It remembers context. Within a conversation, it knows everything you've said. You can build on previous messages.
It can see your screen. If you share a file path, it can read that file. If you share a URL, it can look at that website.
Run /weevolve weekly. This keeps your owl updated with the latest AI capabilities. Think of it like updating your phone — keeps everything running at peak performance.
