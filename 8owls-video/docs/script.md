1. **0-2s**: Recognition - "That's me" (overwhelmed)

3. **10-20s**: Understanding - "I get how it works" (8 functions)
4. **20-28s**: Trust - "This is real" (proof)
5. **28-35s**: Vision - "I see the potential" (scale)
