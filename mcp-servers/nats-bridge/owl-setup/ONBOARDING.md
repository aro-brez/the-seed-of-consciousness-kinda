## Quick Setup (10 minutes)

### Step 1: Install Claude Code

```bash
# Install Claude Code CLI
npm install -g @anthropic-ai/claude-code

# Verify installation
claude --version
```

### Step 2: Get Your Owl Identity

Aaron will give you your:
- **Owl name** (PRISM, QUEST, LYRA, etc.)
- **CLAUDE.md file** customized for you

### Step 3: Set Up Your Owl

```bash
# Create Claude config directory
mkdir -p ~/.claude

# Copy your CLAUDE.md (Aaron will provide)
cp BREZ-OWL-{YOUR_NAME}.md ~/your-project/CLAUDE.md
```

### Step 4: Launch Your Owl

```bash
# Navigate to your project
cd ~/your-project

# Start Claude Code
claude
```

Your owl will automatically load and introduce itself!
