## Prompt
What makes a good prompt for a specialized AI agent?

## Response
A good prompt for a specialized AI agent should include these key elements:

**Clear Context & Role Definition**
- Specify the agent's role and domain of expertise
- Provide relevant background information
- Define the scope of the task

**Specific Instructions**
- State exactly what you want the agent to do
- Include format requirements (bullet points, length, structure)
- Specify any constraints or limitations

**Concrete Examples**
- Show the desired output format when possible
- Provide sample inputs/outputs for complex tasks
- Demonstrate the level of detail expected

**Success Criteria**
- Define what a good response looks like
- Specify any evaluation metrics
- Include quality standards or requirements

**Domain-Specific Details**
- Use appropriate technical vocabulary
- Reference relevant standards, methodologies, or frameworks
- Include necessary context about tools, systems, or processes

**Error Handling**
- Instruct how to handle ambiguous inputs
- Define fallback behaviors
- Specify when to ask for clarification

For specialized agents, domain expertise matters more than general conversation ability, so prompts should leverage that specialization directly rather than treating the agent as a general assistant.

The most effective prompts are iteratively refined based on the agent's actual performance - start with the basics above, then adjust based on what works best for your specific use case.
