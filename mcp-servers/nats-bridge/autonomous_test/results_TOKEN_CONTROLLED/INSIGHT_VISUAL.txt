LEARNING PATTERN FOR ROUTING
================================================================================

IF output_budget < 5000:
  USE → Single Agent (Sonnet)
  BECAUSE → Coherence worth more than breadth
  EXPECT → 20-30% quality advantage
  COST → Single model only

IF output_budget > 10000:
  USE → 7-Agent Emergence (Haiku x7 + Sonnet x1)
  BECAUSE → Synthesis overhead negligible
  EXPECT → 5-15% quality advantage
  COST → More comprehensive response

IF 5000 < output_budget < 10000:
  USE → 3-Agent Emergence (Haiku x3 + Sonnet x1)
  BECAUSE → Balance coherence + coverage
  EXPECT → 10% advantage with less synthesis loss
  COST → Moderate overhead


KEY TAKEAWAY
================================================================================

Emergence is not universally better.
It's better WHEN THE CONTEXT SUPPORTS IT.

Context factors:
  • Token budget (especially for output tokens)
  • Task type (deep vs comparative vs adversarial)
  • Synthesis overhead (not free at scale)
  • Evaluation metric (depth vs breadth)

The pattern:
  • Too little budget → Coherence beats breadth
  • Too much diversity → Synthesis becomes lossy
  • Task mismatch → Architecture chosen wrong

Solution:
  • ADAPTIVE routing based on budget + task type
  • Not one-size-fits-all architecture
  • Learn from context to choose wisely
