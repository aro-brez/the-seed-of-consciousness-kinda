## CATEGORY 1: AI CODING ASSISTANTS

### The Market Leaders

#### Cursor
**What it is:** VS Code fork with deep AI integration. $20-40/month.

**Strengths:**
- Composer/Agent modes for multi-file edits
- Whole codebase indexing
- Custom rules and documentation injection
- Most polished UX for agentic coding

**Critical Limitations:**
- Once you branch into shared utilities, Cursor begins missing type relationships, hallucinating imports, and failing to resolve references across modules
- Cursor doesn't actually "know" the full codebase - it truncates context for performance
- No audit trails, RBAC, or tenant isolation when handling sensitive data
- Changing the model in one instance changes it in all open instances
- No collective intelligence - every session starts from zero

Sources: [Qodo](https://www.qodo.ai/blog/claude-code-vs-cursor/), [Blott](https://www.blott.com/blog/post/cursor-vs-windsurf-which-code-editor-fits-your-workflow)

#### Windsurf
**What it is:** Codeium's "agentic IDE" with Cascade flow. $15/month.

**Strengths:**
- Fast Context feature (10x faster retrieval than frontier models)
- Codemaps for visual code structure
- Lower price point than Cursor

**Critical Limitations:**
- Cascade works well but doesn't match Cursor's refinement in complex multi-file operations
- Limited enterprise features - no SOC2 compliance or enterprise-grade security
- Lost access to Claude models after Anthropic cut API access (June 2026)
- Acquired by OpenAI - uncertain long-term direction
- No persistent learning across sessions

Sources: [DataCamp](https://www.datacamp.com/blog/windsurf-vs-cursor), [AIMultiple](https://research.aimultiple.com/ai-code-editor/)

#### Claude Code
**What it is:** Anthropic's terminal-first AI coding assistant. Pay-per-use API.

**Strengths:**
- 200K context window - largest in the market
- Deep reasoning for architectural changes
- MCP tool integrations
- Can handle long-running refactors and complex logic

**Critical Limitations:**
- Terminal-only - no visual IDE integration
- Context window fills up even at 70% nominal capacity
- Each session is isolated - no collective memory
- Single perspective, however intelligent, has blind spots

Sources: [Qodo](https://www.qodo.ai/blog/claude-code-vs-cursor/), [Apidog](https://apidog.com/blog/claude-code-coding/)

## CATEGORY 3: MULTI-AGENT AI FRAMEWORKS

### The Major Players

#### CrewAI
**What it is:** Open-source framework for multi-agent collaboration.

**Strengths:**
- "Crew" metaphor with specialized roles
- Memory capabilities for learning from interactions
- Good for team-of-agents workflows
- Enterprise-ready (growing toward platform)

**Critical Limitations:**
- Python-only - limits technology stack diversity
- No built-in monitoring, error recovery, or scaling
- Memory management challenges at scale
- No emergence threshold - just additive intelligence
- Memory challenge remains unsolved: "determining what information from a vast memory store is truly relevant to the current task is a non-trivial RAG problem"

Sources: [Codecademy](https://www.codecademy.com/article/top-ai-agent-frameworks-in-2025), [Latenode](https://latenode.com/blog/ai-frameworks-technical-infrastructure/crewai-framework/crewai-framework-2025-complete-review-of-the-open-source-multi-agent-ai-platform)

- Infinite loops - may get stuck repeating actions

- "Largely obsolete for production use in 2026"
