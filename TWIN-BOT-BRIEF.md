## WHAT DOES IT DO?

**Twin A1 Action Agent:**

1. You describe a goal in plain language
2. A1 logs into the web app
3. A1 navigates the UI like a human (clicks, types, extracts)
4. A1 completes the task autonomously
5. Schedule it or run on-demand

**Example:** "Monitor these 5 Twitter accounts every hour and extract any crypto mentions"
→ Twin logs into Twitter, navigates feeds, scrapes content, returns data.

**Key Innovation:** If a site doesn't have an API, Twin can still automate it. Browser-as-API paradigm.
