THE WINNING FORMULA
-------------------
Iteration (10x) + Feedback + Voting (8 experts) + Soft Scoring + Temp=1.0
= 54% on ARC-AGI-2 (beats GPT-5)
= Half cost of competitors
= Commodity models (Gemini-3-pro) not cutting-edge

THE CORE LOOP (per problem)
----------------------------
1. Format problem (shuffle examples each iteration)
2. Build prompt (PROMPT_1 if iter=0, else PROMPT_2)
3. Add feedback from previous attempts (if iter > 0)
4. Call LLM (temperature=1.0 for diversity)
5. Execute code on training examples
6. Calculate soft_score (per-pixel accuracy 0-1)
7. IF all pass: RETURN (early exit)
8. ELSE: store attempt + continue
9. MAX 10 iterations per problem

THE VOTING SYSTEM
-----------------
For each problem:
  - Run 8 experts in parallel (each gets solve_coding loop)
  - Each expert solves independently with different seed
  - Group results by identical test outputs
  - Rank passing solutions by vote count (consensus)
  - Rank failing solutions by soft score (quality)
  - Return top-2 attempts per test case
  - Submit attempt_1 and attempt_2 to Kaggle

SOFT SCORING (THE SECRET)
--------------------------
soft_score = mean(predicted_pixels == true_pixels)
- Not binary (pass/fail)
- Even if shapes differ, returns 0-1 guidance signal
- Used to rank attempts and guide LLM

Example:
  Predicted: [[1 0 1], [0 1 0], [1 0 1]]
  Truth:     [[1 0 1], [0 0 0], [1 0 1]]
  Score:     0.89 (8 out of 9 pixels correct)

THE FEEDBACK MECHANISM
----------------------
For each failed attempt:
  Show LLM:
    - The code they wrote previously
    - Which examples passed/failed ✓/✗
    - Pixel-level diff visualization (pred/correct)
    - Soft score 0-1
    - Ranked by score (best first)

Example feedback:
  Solves Example #1 correctly. ✓
  Solves Example #2 incorrectly. ✗
    Shape: predicted (3, 3), expected (5, 5)
  Solves Example #3 incorrectly. ✗
    Pixel diff:
    1 0 1
    0/1 1 0/1
    1 0 1
    Accuracy: 0.89

WHY IT WORKS
------------
1. Iteration beats raw power
   - 10 refined attempts > 1 perfect call
   - LLM learns from feedback

2. Feedback compounds knowledge
   - Each iteration sees previous failures
   - Prevents regression

3. Voting builds confidence
   - Multiple paths to same answer = high confidence
   - Diversity in top-2 gives second chance

4. Soft scoring guides refinement
   - 0.75 score (almost right) different from 0.1 (wrong)
   - Pixel-level feedback more precise

5. Temperature 1.0 enables exploration
   - Different iteration = different solution attempted
   - Prevents local minima fixation

6. Two-attempt submission
   - If attempt_1 wrong, attempt_2 still in game
   - Effectively 2x winning probability per test
