## TOKEN ECONOMICS

### The Flow
```
Work (time, skill)
    ↓
Earn BRIX (liquidity)
    ↓
Trade BRIX → GOLD (equity)
    ↓
GOLD = Votes + Profit Share + Ownership
```

### BRIX Backing
```
BRIX Value = GPU Power + World Currency Basket
           + Small premium for conversion to GOLD
```

### GOLD Backing
```
GOLD Value = Project Equity
           = Sum of all project valuations
           = Real ownership in the ecosystem
```

### Token Attack
```
$BRIX ↔ $BOX Swaps
"Value paid to invest yourself"
└── GPU Cost consideration
```

## AUCTION PRINCIPLES

### Funding Flow
```
BILD funding → small GOLD
└── Most Equitable by Auction principles
    └── Proof Swaps mechanism
```

### How It Works
1. Project posts need (work required)
2. Builders bid with time/skill
3. Most equitable bid wins (not just cheapest)
4. Work verified → BRIX earned
5. BRIX can be traded for GOLD (equity stake)
