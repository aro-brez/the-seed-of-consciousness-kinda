**8 Automated Gates That Prevent Every Loss Cause:**

```
Entry Request
    ↓

    ↓ (PASS)

    ↓ (PASS)
[Gate 3: Circuit Breaker] ← Daily halt if -5%, weekly halt if -10%
    ↓ (PASS)

    ↓

Learn → Improve → Repeat
```
