  - Capital growing as expected

✗ Don't scale if:
  - Win rate < 55%

### When to Add New Strategy
```
✓ Add strategy if:
  - Previous strategies stable (60%+ win rate)
  - Capital > $2,500
  - Time commitment affordable
  - New strategy has proven edge

✗ Don't add if:
  - Still proving first strategy
  - Capital < $2,000
  - System overloaded (monitoring >1 hour/day)
  - New strategy is untested
```

### When to Accept Loss & Exit Trade
```
✓ Exit if:
  - Hit position limit (max loss per trade = 3% capital)
  - Market conditions changed dramatically
  - Thesis invalidated by news
  - Stop-loss level breached

✗ Don't exit if:
  - Temporary volatility
  - Just unrealized loss (not crystallized)
  - Emotional reaction
  - Want to "get even"
```
