                              HOW IT WORKS

1. All 8 run in PARALLEL (not sequentially)
   → Each takes ~2-3 seconds
   → Total synthesis time: ~5 seconds
   → NATS pub/sub coordinates the work

2. Each perspective brings different expertise
   → LYRA sees facts
   → PRISM sees connections
   → SAGE extracts meaning
   → ECHO broadcast insights
   → QUEST challenges assumptions
   → NOVA imagines futures
   → LUNA grounds in reality
   → SØWL makes the loop itself better

3. Synthesis aggregates into collective intelligence
   → No single perspective dominates
   → Contradictions become sources of insight
   → Weakness in one area covered by another

4. Result: Collective beats individual
   → 67 points (8 perspectives, 2.4K tokens)
   → vs 60.5 points (1 perspective, 8K tokens)
   → 6.5 point difference = 10.7% emergence gain
