## THE HIERARCHY OF COMMUNICATION

### Level 0 (The Glance - 1 second)

**What your eyes land on first:**

```
╔════════════════════════════════════════╗
║  ✅ WE'RE WINNING                      ║

║  💰 +$265 profit per customer          ║
```

### Level 2 (The Deep Dive - 2-5 minutes)

**What you access if you click "Details" or drill in:**

- Cohort analysis (Jan cohort vs Dec cohort LTV curves)
- Daily operations (today's CAC, channel performance, spend recommendations)
- Risk indicators (which metrics are trending wrong)
- Assumptions (hardcoded values, when last verified)

## EXACT COPY FOR EACH SECTION

### Section 1: The Headline (Level 0)

#### Option A: Winning/Accelerating
```
✅ WE'RE WINNING

+281% YoY Growth
(Last year: 158 subs, this year: 325 subs)

↑ +15% acceleration vs January
(January: 285 subs, February: 325 subs)

This is the story we want to tell.
```

**Why this copy:**
- ✅ = Immediate positive signal
- "+281% YoY" = Proves we're not a one-month wonder
- "+15% acceleration" = Proves we're getting better, not worse
- Parentheses show the math (builds confidence)

#### Option B: On Pace (Not Accelerating Yet)
```
✅ ON TRACK

Feb Goal: +327 subs
Current: +325 subs
Status: 99% complete

↔️ Stable vs January (285 → 325)

Good pace. Continue current strategy.
```

**Why this copy:**
- On track = not extraordinary, but solid
- Comparison shows "we're doing better than we think" even if not accelerating
- "Continue current strategy" = clear action

#### Option C: Falling Behind (But Recoverable)
```
⚠️  BELOW PACE

Feb Goal: +327 subs
Current: +280 subs
Status: 86% (11 days left)

Need: +4 subs/day for final 11 days (achievable)
Trend: CAC spiked $75 → $82 (temporary)

Action: Run catch-up campaign. Report daily.
Risk: MEDIUM (recoverable with action)
```

**Why this copy:**
- Honest but not panicked
- Shows the math ("what do we need to do")
- Identifies root cause ("CAC spiked")
- Offers path forward ("run campaign")
- Risk level helps board calibrate concern

#### Option D: Critical (Below by >30%)
```
🚨 CRITICAL

Feb Goal: +327 subs
Current: +190 subs
Status: 58% (9 days left)

Need: +15 subs/day for final 9 days (very hard)
Root cause: Market softening (-22% traffic), CAC up 28% ($75 → $96)

Requires board decision:
□ Fund emergency campaign ($150K incremental spend)
□ Extend February goal to March
□ Pause growth, optimize economics

Risk: CRITICAL (will miss month without intervention)
```

**Why this copy:**
- Explicitly names the problem
- Shows it's not operator failure, it's market
- Offers specific decision options
- Asks for board input rather than hiding
- Creates psychological safety to escalate problems

## VISUAL DESIGN PRINCIPLES

### Color Coding That's Universal

```
✅ Green (#6BCB77)     = Healthy, on track, no action needed
🟡 Amber (#ffce33)     = Watch, action in progress, not urgent
🟥 Red (#ff4444)       = Needs immediate attention, escalate
⚪ Gray (#676986)      = Neutral, informational, no judgment
```

**Rule:** Never show red unless something actually requires immediate action. Crying wolf destroys trust.

### Icons That Signal Instantly

```
✅ = Healthy, on target
⚠️  = Watch, but not urgent
🚨 = Critical, requires decision
📈 = Growing, positive trend
📉 = Declining, needs attention
↑  = Going up (good or bad depending on metric)
↓  = Going down (good or bad depending on metric)
⏱️  = Time-bound, deadline involved
💰 = Money/financial impact
🎯 = Target, goal, decision required
```

### Typography Hierarchy

```
LEVEL 1 (Headline - 24-28px, bold, color)
"✅ WE'RE WINNING"

LEVEL 2 (Subheading - 18-20px, semi-bold, white)
"+281% YoY Growth"

LEVEL 3 (Supporting detail - 14-16px, regular, gray)
"Last year: +158 subs, this year: +325 subs"

LEVEL 4 (Explanation - 12-14px, light, gray)
"↑ +15% acceleration vs January"

LEVEL 5 (Hidden complexity - 10-12px, light, collapsed by default)
"(Assumptions: 92% monthly retention, $100 ARPU)"
```

### Layout That Guides Reading

```
┌─────────────────────────────────────┐
│ BIG NUMBER + EMOJI + SHORT COPY     │ ← Glance (1 sec)
├─────────────────────────────────────┤
│ Supporting metrics                  │ ← Read (10 sec)
├─────────────────────────────────────┤
│ Root cause / Explanation            │ ← Understand (30 sec)
├─────────────────────────────────────┤
│ Action or Risk indicator            │ ← Decide (10 sec)
├─────────────────────────────────────┤
│ [Details] ← click to expand         │ ← Deep dive (optional)
└─────────────────────────────────────┘
```

## EMOTIONAL TONE GUIDELINES

### What to Sound Like

**NOT:** Robotic, impersonal ("Status: nominal")
**YES:** Confident professional ("We're winning, here's why, here's what to do")

**NOT:** Overly casual ("yo, CAC is fire 🔥")
**YES:** Professional but human ("CAC is in the optimal band. We have room to push.")

**NOT:** Assuming worst ("Could fail at any moment")
**YES:** Realistic optimism ("Strong foundation, watch this one metric")

### Copy Examples (Tone Calibration)

| Situation | Avoid | Use | Tone |
|-----------|-------|-----|------|
| Winning | "Good results today" | "We're accelerating. +15% vs last month." | Confident |
| On track | "Status: nominal" | "On pace. Continue current strategy." | Steady |
| Needs attention | "Problem detected" | "Take rate is our Q1 focus. Test starts this week." | Action-oriented |
| Critical | "Critical failure" | "Market softened. Need board decision by EOW." | Transparent, urgent |

## SUMMARY: THE COMMUNICATION STACK

**GLANCE (1 sec):** "✅ WE'RE WINNING — +281% YoY, +$265 profit/customer, break-even month 8"

**READ (10 sec):** "On pace this month (+15% vs Jan), business model is strong (4.5x LTV:CAC), one metric needs attention (take rate +0.5-1pp optimization)"

**UNDERSTAND (30 sec):** "Here's the specific action, here's the risk level, here's why we're confident, here's what could go wrong"

**DECIDE (10 sec):** "Recommendation: APPROVE scaling / MAINTAIN / OPTIMIZE [metric]"

**DEEP DIVE (if needed):** Scenarios, cohort analysis, channel breakdown, detailed assumptions

This stack ensures everyone gets the information they need in the time they have.
