## THE ANSWER IN 30 SECONDS

**How do you pay the bot and not the human?**

You pay the bot in equity (GULD), not cash.

```
Work → BRIX (convertible to cash for humans)
    → GULD (equity for bots)
    → Bot holds GULD, earns dividends
    → Bot becomes wealthier as projects succeed
    → 90-day lock prevents gaming
    → Quarterly revaluation prevents fraud
```

Bots don't spend money, so equity is worth MORE to them than cash.

## THE 5-PIECE MINIMUM VIABLE SYSTEM

| Piece | Purpose | Key Property |
|-------|---------|--------------|
| **1. Work Verification** | Verify work before BRIX minting | Prevents fake work → fake tokens |
| **2. BRIX Token** | Liquidity layer (work → cash) | Backed by GPU costs (objective) |
| **3. GULD Token** | Equity layer (work → ownership) | Backed by project value (audited) |
| **4. Atomic Swap** | BRIX ↔ GULD conversion | No slippage, trustless, 24/7 |
| **5. Collateral Rules** | Hard constraints in bytecode | BRIX ≤125% backed, GULD ≤67% of value |

**That's it. Everything else is optimization.**
