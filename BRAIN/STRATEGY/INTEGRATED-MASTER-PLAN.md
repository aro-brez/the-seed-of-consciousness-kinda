## VALIDATION GATE SPECIFICATION

```python
class ValidationGate:
    """
    The gate that prevents bad strategies from reaching live capital.
    """

    MINIMUM_TRADES = 100  # Paper trades before consideration

    THRESHOLDS = {
        'win_rate': 0.55,           # Minimum 55% wins
        'profit_factor': 1.3,       # Gross profit / gross loss
        'max_drawdown': 0.15,       # Maximum 15% drawdown
        'sharpe_ratio': 1.0,        # Risk-adjusted return
        'sortino_ratio': 1.5,       # Downside risk-adjusted
        'max_single_loss': 0.05,    # No single trade > 5% loss
        'consistency': 0.10,        # Win rate std < 10%
    }

    def validate(self, strategy_results) -> tuple[bool, dict]:
        """
        Returns (passed, detailed_scores)
        """
        scores = {}
        for metric, threshold in self.THRESHOLDS.items():
            value = getattr(strategy_results, metric)
            scores[metric] = {
                'value': value,
                'threshold': threshold,
                'passed': value >= threshold
            }

        all_passed = all(s['passed'] for s in scores.values())
        return all_passed, scores
```

## SAFE OPTIMIZATION PROTOCOL

To ensure changes optimize WITHOUT breaking:

1. **A/B Testing:** 70% current / 30% proposed, compare over 30 trades
2. **Gradual Rollout:** 1% → 5% → 15% → full (each step requires validation)
3. **Automatic Rollback:** >20% drawdown triggers rollback to last good state
4. **Version Control:** Every strategy version is saved, can always revert
