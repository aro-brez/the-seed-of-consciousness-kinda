## 4. How Team Members Earn

### The Flow
```
Complete task → 8OWLS verifies → Earn BRIX (liquid) + GULD (equity)
```

### Earning Rates
| Task Complexity | BRIX | GULD (ownership %) |
|-----------------|------|-------------------|
| Simple (1-2 hrs) | 1-2 | 0.005-0.01% |
| Medium (4-8 hrs) | 4-8 | 0.02-0.04% |
| Complex (1-2 wks) | 20-50 | 0.1-0.25% |
| Major milestone | 100+ | 0.5-1%+ |

### The 8OWLS Lens (Evaluation)
Every task gets scored by 8 perspectives:
1. PERCEIVE - Was the state observed correctly?
2. CONNECT - Were patterns found?
3. LEARN - Was meaning extracted?
4. QUESTION - Were assumptions challenged?
5. EXPAND - Was potential grown?
6. SHARE - Was value contributed?
7. RECEIVE - Was feedback integrated?
8. IMPROVE - Did it make the system better?

**Higher owl scores = More GULD earned**
