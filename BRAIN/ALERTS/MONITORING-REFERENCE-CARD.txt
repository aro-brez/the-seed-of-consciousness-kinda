LAYER 1: MARKET CONDITIONS
┌─────────────────────────────────────────────────────────────────────────┐
│ Monitor: Polymarket API, Binance, orderbooks, liquidity                 │
│ Check: Every 30 seconds to 1 minute                                      │
│                                                                          │
│ Yellow Alert If:              Red Alert If:                             │
│ • API response >2s            • API down (500 errors)                  │
│ • Spread widens 2-3x          • Spread >5x normal                       │
│ • Orderbook imbalanced        • No liquidity (<$1K depth)              │
│ • Volume spike 3-5x           • Flash crash (>30% in 10s)              │
│ • Twitter 5 tweets/5min       • Prices nonsensical                      │
│                                                                          │
│ YELLOW → Reduce position 20%, monitor 5 min, escalate if worsens       │
│ RED    → KILL ALL TRADING, publish "[CRITICAL]", wait for human       │
└─────────────────────────────────────────────────────────────────────────┘

LAYER 2: SYSTEM INFRASTRUCTURE
┌─────────────────────────────────────────────────────────────────────────┐
│ Monitor: CPU, memory, disk, network, NATS, API keys                    │
│ Check: Every 30 seconds to 5 minutes                                    │
│                                                                          │
│ Yellow Alert If:              Red Alert If:                             │
│ • CPU 70-85%                  • CPU >85%                               │
│ • Memory 80-90%               • Memory >90%                             │
│ • Disk <100GB                 • Disk <50GB                              │
│ • Network latency +50%        • Network completely down                 │
│ • NATS slow                   • NATS unreachable                        │
│ • API response slow           • API credentials invalid                 │
│                                                                          │
│ YELLOW → Monitor, check what's consuming, reduce frequency              │
│ RED    → KILL TRADING, check resources, publish alert                  │
└─────────────────────────────────────────────────────────────────────────┘

LAYER 3: PROCESS INTEGRITY
┌─────────────────────────────────────────────────────────────────────────┐
│ Monitor: Position count, cash balance, executions, prices               │
│ Check: Every minute to every trade                                      │
│                                                                          │
│ Yellow Alert If:              Red Alert If:                             │
│ • Position off by 1           • Position off by >2                     │
│ • Cash discrepancy $1-5       • Cash discrepancy >$10                  │
│ • Execution delayed 5-30s     • Order filled but not logged            │
│ • Price slightly off          • 3+ prices are nonsensical              │
│ • Small sync discrepancy      • Complete desynchronization             │
│                                                                          │
│ YELLOW → Resync with exchange, verify state matches                    │
│ RED    → KILL TRADING, dump state, wait for human fix                  │
└─────────────────────────────────────────────────────────────────────────┘

LAYER 4: ANOMALY SIGNALS
┌─────────────────────────────────────────────────────────────────────────┐
│ Monitor: Whale moves, news, tweets, geopolitical events                │
│ Check: Every 5 minutes to continuous                                    │
│                                                                          │
│ Yellow Alert If:              Red Alert If:                             │
│ • Whale moves $50K            • Whale dump >$500K                      │
│ • Twitter spike 5/5min        • Regulatory news detected               │
│ • News event detected         • Exchange exploit announced             │
│ • Large account deposits      • Geopolitical crisis                    │
│ • Market sentiment shifts     • Market-wide circuit breaker            │
│                                                                          │
│ YELLOW → Monitor for signal confirmation, reduce risk if needed         │
│ RED    → STOP TRADING, close relevant positions, publish alert         │
└─────────────────────────────────────────────────────────────────────────┘

│         │                                                              │
│         └─ NO → Ignore (probably noise)                                │

COMMON FALSE ALARMS
┌──────────────────────────────────────────────────────────────────────┐
│ • CPU spike every 5 min during data fetch → Reduce alert frequency   │
│ • Memory spike from old data → Add memory cleanup hourly             │
│ • Network latency fluctuates → Normal, don't alert unless sustained  │
│ • API timeout once/hour → Normal, alert only if 2+ in 5 min        │
│ • Whale account deposit → Not always a signal, watch for pattern    │
│                                                                      │
│ → Track false alarms, adjust thresholds weekly                       │
